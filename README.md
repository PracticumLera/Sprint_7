# Sprint_7 - Автотесты API Яндекс.Самокат

Учебный проект по автоматизации тестирования REST API сервиса [Яндекс.Самокат](https://qa-scooter.praktikum-services.ru/docs/).

## Что покрыто

- создание курьера и проверка ошибок валидации;
- авторизация курьера;
- создание заказов с параметризацией цветов (BLACK, GREY);
- получение списка заказов;
- удаление курьера;
- принятие заказа;
- получение заказа по трек-номеру.

## Стек

- Java 11
- Maven
- JUnit 4
- RestAssured
- Allure

## Запуск тестов

mvn clean test

## Генерация отчёта Allure

mvn allure:serve
